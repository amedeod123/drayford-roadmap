# Drayford — W27 Roadmap

Internal planning site for Drayford Corporation's Y Combinator Winter 2027 application.

**https://amedeod123.github.io/drayford-roadmap/**

The page content is encrypted (AES-256-GCM, PBKDF2-SHA256, 310k iterations) and unlocks with a
passphrase in the browser. The repository is public only because GitHub Pages requires it; nothing
readable is published. Ask Amedeo for the passphrase.

Source (`content.html`, `shell.html`, `build.py`) is kept out of this repo on purpose — publishing it
would publish the plaintext. It lives in `~/drayford/docs/w27_roadmap_src/`.

To update: edit the source, run `python3 build.py`, copy `index.html` here, commit.
